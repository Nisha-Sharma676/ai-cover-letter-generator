
# AI Cover Letter Generator

## Project Overview
A web application that generates a professional cover letter using candidate details, job role, target company, and key skills.

## Technologies Used
- HTML for the form and output section
- CSS for styling and responsive design
- JavaScript for form handling and cover letter generation
- Clipboard API for copying the generated letter

## Prompt Template
Write a professional cover letter for a job applicant using the following details:

Candidate Name: [Candidate Name]
Job Role: [Job Role]
Target Company: [Target Company]
Key Skills: [Key Skills]

The cover letter should have a professional tone, clear paragraphs, and a polite closing. Do not invent qualifications or work experience.

## Current Implementation
The current version uses a predefined JavaScript template to generate the cover letter. AI API integration is planned for the next phase.
