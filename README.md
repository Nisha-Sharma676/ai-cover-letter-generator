# AI Cover Letter Generator

An AI-powered web application that generates professional, personalized cover letters based on user-provided details.

## Features
- Enter candidate name, job role, target company, and key skills.
- Generate a cover letter using the Gemini API.
- Copy the generated cover letter to the clipboard.
- Responsive user interface.
- Server-side API integration to keep the API key out of frontend code.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Google Gemini API

## Setup and Run Locally

1. Clone this repository.
2. Install dependencies:

   `npm install`

3. Create a `.env` file in the project root and add your own API key:

   `GEMINI_API_KEY=your_api_key_here`

4. Start the server:

   `npm start`

5. Open `http://localhost:3000` in your browser.

## Security
Keep your API key private. Never upload your `.env` file to GitHub.
